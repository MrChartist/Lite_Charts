DEMO · custom series

StackedAreaSeries

Several values per row, stacked. The row's total drives autoscale and the legend.

chart.addSeries(StackedAreaSeries, { title: 'Volume by venue' })
  .setData([{ time: '2024-03-01', values: [3, 5, 2] }]);

HeatmapSeries

A column of price buckets per bar, each with an intensity from 0 to 1.

chart.addSeries(HeatmapSeries, { title: 'Depth' })
  .setData([{ time, low: 100, step: 0.5, cells: [0, 0.2, 0.9] }]);

RoundedCandlesSeries

The built-in candle rows with rounded bodies; narrow bars fall back to the fast painter.

chart.addSeries(RoundedCandlesSeries, { radius: 0.6 })
  .setData(bars);

WhiskerBoxSeries

Min, quartiles, median and max per bar: a range of outcomes, not one price.

chart.addSeries(WhiskerBoxSeries, { title: 'Forecast' })
  .setData([{ time, min: 1, q1: 2, median: 3, q3: 4, max: 6 }]);
