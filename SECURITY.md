# Security Policy

## Supported versions

Only the latest released version of Chartist Lite receives security fixes.

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

Use the **"Report a vulnerability"** button on the repository's Security tab. This opens a private security advisory that only the maintainers can see.

## What to expect

Chartist Lite runs in the browser. It makes no network requests and stores nothing. A report should describe the input or steps that cause the problem, the version you used, and the browser you used.
