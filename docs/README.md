# Chartist Lite documents

Every document in this package, one line each. New here? Start with [Getting started](guide/getting-started.md), or the [README](../README.md) for the whole picture.

| I want to | Read |
|---|---|
| Draw my first chart | [Getting started](guide/getting-started.md): a tag, a module or React |

| Put it on any page | [Embedding the chart](guide/embedding.md): the element, ES module, React, iframe; attributes and data formats |
| Choose how prices look | [Series types](guide/series-types.md): candlestick, bars, line, area, histogram, baseline |
| Switch to Renko, Kagi or point and figure | [Chart types](guide/chart-types.md): 16 chart types through `applyChartType`, and the time axis of brick types |
| Add moving averages and oscillators | [Indicators](guide/indicators.md): the indicators as plain functions, with live forms |
| Stack RSI under the price | [Panes and scales](guide/panes-and-scales.md): panes, overlay scales, log and percent modes |
| Show exchange time | [Time and time zones](guide/time-and-time-zones.md): the gap-free axis, IANA zones, number rules |
| Let readers draw on the chart | [Drawing tools](guide/drawing-tools.md): 53 tools in 7 groups, toolbar, keys, undo, JSON, your own tools |
| Stream live prices | [Live data](guide/live-data.md): `connectLive`, the one-tag element, statuses, your own provider, React, CSP, privacy |
| Match my brand | [Theming](guide/theming.md): dark and light, colours, fonts, the legend, the attribution link |
| Add tooltips, alerts or replay | [Tooltips, alerts and more](guide/extras.md): tooltips, watermark, range switcher, compare, alerts, replay, bands, custom series |
| Draw my own marks | [Plugins and primitives](guide/plugins.md): price lines, markers, the primitive contract |
| Reach every reader | [Accessibility](guide/accessibility.md): keyboard, spoken bars, fallback text, what was tested |
| Move a chart over | [Coming from Lightweight Charts](guide/coming-from-lightweight-charts.md): same names, where behaviour differs |
